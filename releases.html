    LumaOS is a desktop Linux distribution based on Ubuntu and featuring the niri Wayland compositor. It is distributed as a minimalist live image, with a carefully designed dark theme, a curated selection of desktop tools, an application installer called Luma Store, the Foot terminal, and the Calamares system installer. The distribution also supports installing Flatpak packages. LumaOS is designed for users who prefer a scrollable tiling window management workflow on their desktop.

  • 2026-10-24Voyager 26.04.1DistroWatch · Homepage · ISO

    Voyager Live is an Xubuntu-based distribution and live DVD showcasing the Xfce desktop environment. Its features include the Avant Window Navigator or AWN (a dock-like navigation bar), Conky (a program which displays useful information on the desktop), and over 300 photographs and animations that can be used as desktop backgrounds. The project also develops several other editions of Voyager Live - a "GE" edition with GNOME Shell, a "GS" variant for Gamers, and a separately-maintained flavour based on Debian's "stable" branch.

  • 2026-10-24Quirinux 2.3DistroWatch · Homepage · ISO

    Quirinux is a Devuan-based Linux distribution designed for the development of animated films. The project provides tools to create an animated film using various common techniques (traditional, digital, cut-out, CGI-3D, stop motion, motion graphics) using open-source software. The distribution uses the Xfce desktop and its main features include ease of installation with the Calamares system installer, GIMP image editor that comes with a configurator tool and extra plugins, and choice of themes and desktop layouts.

  • 2026-10-23HAOS 18.4-rc2DistroWatch · Homepage · ISO

    Home Assistant OS (HAOS) is an independently-developed, Linux-based operating system optimised to run Home Assistant, an open-source home automation tool. It focuses on local control and privacy. HAOS uses Docker as its container engine and deploys Home Assistant Supervisor as a container. Home Assistant Supervisor in turn uses the Docker container engine to control Home Assistant Core and Apps in separate containers. The product is available for various single-board computers, like Raspberry Pi or ODROID, but it also supports x86_64 systems with UEFI boot mode.

  • 2026-10-23Flatcar 4757.2.2DistroWatch · Homepage · ISO

    Flatcar Container Linux is a container-optimized operating system based on Gentoo Linux. It is a minimal operating system image which includes only the tools needed to run containers and it supports all of the popular methods for running containers. The distribution ships an immutable filesystem and includes automatic atomic updates. Flatcar Container Linux runs on most cloud providers, virtualization platforms and bare metal servers.

  • 2026-10-23Lyra 16.1-rc1DistroWatch · Homepage · ISO

    Lyra OS is a Brazilian desktop and server Linux distribution based on openSUSE Tumbleweed, a rolling-release variant of openSUSE. The desktop edition features a customised GNOME desktop. It provides a simple and intuitive system installer called Lyra Install and a comprehensive control centre termed Vega, which is also available as a command-line and web-based application in Lyra's Server edition. The distribution also ships with LinuxToys, a unified system management, configuration and software installation tool. Lyra OS supports Portuguese (both Brazilian and European) and English languages.

  • 2026-10-23T4n OS 20261023DistroWatch · Homepage · ISO

Besides some of the standard characteristics inherited from upstream, such as rolling release model, XBPS package manager, and runit init system, the project also features VUR (Void User Repository), a software repository concept inspired by Arch's AUR (Arch User Repository).

  • 2026-10-23KDE neon 20261018DistroWatch · Homepage · ISO

    KDE neon is a Ubuntu-based Linux distribution and live DVD featuring the latest KDE Plasma desktop and other KDE community software. Besides the installable DVD image, the project provides a rapidly-evolving software repository with all the latest KDE software.   • 2026-10-23FLinux 17.2DistroWatch · Homepage · ISO

    FLinux is a minimalist Linux distribution forked from Tiny Core Linux. It is built with FLTK, a cross-platform C++ GUI toolkit. The distribution uses the flwm window manager and includes a bare minimum of lightweight applications, such as Dillo (a web browser), Fluff (a file manager) and flpicsee (an image viewer). Extra applications can be install through a graphical software management utility and the project maintains a repository of custom-built packages, in addition to those provided by Tiny Core Linux. The distribution is available in two variants - one without any WiFi support and one with a wide range of wireless firmware included. FLinux is designed to be extremely lightweight; it can run in installed mode without swap on systems with as little as 96 MB of memory.

  • 2026-10-22Unraid 7.3.4DistroWatch · Homepage · ISO

Some of Unraid's main features include the ability to mix and match drives of different sizes, an easy-to-use web interface for managing storage, virtual machines and Docker containers, protection to safeguard against drive failures, ability to expand the storage by adding more drives.

  • 2026-10-22NagisinnraLinux 1.0.9DistroWatch · Homepage · ISO

    NagisinnraLinux is a Japanese Linux distribution based on Debian's "Stable" branch. Featuring a lightweight Xfce desktop, it is specifically designed to revive older hardware and provide a snappy and minimal, yet fully functional desktop environment for daily use. The distribution's main features include out-of-the-box support for the Japanese language, advanced memory optimisation, use of zram compression to guarantee smooth multitasking, and removal of unnecessary and redundant services to maximise battery life and CPU responsiveness.

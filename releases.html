  • 2026-10-31Lyra 16.1-rc3DistroWatch · Homepage · ISO

    Lyra OS is a Brazilian desktop and server Linux distribution based on openSUSE Tumbleweed, a rolling-release variant of openSUSE. The desktop edition features a customised GNOME desktop.   • 2026-10-30OpenIndiana 20261030DistroWatch · Homepage · ISO

    OpenIndiana is a continuation of the OpenSolaris operating system. It was conceived during the period of uncertainty following the Oracle takeover of Sun Microsystems, after several months passed with no binary updates made available to the public. The formation proved timely, as Oracle discontinued OpenSolaris soon after in favour of Solaris 11 Express, a binary distribution with a more closed development model to début later this year. OpenIndiana is part of the illumos Foundation, and provides a true open-source community alternative to Solaris 11 and Solaris 11 Express, with an open development model and full community participation.

  • 2026-10-29Proton 2026.11.01DistroWatch · Homepage · ISO

  • 2026-10-29CarotOS 1.3DistroWatch · Homepage · ISO

    CarotOS is a specialist Debian-based Linux distribution designed primarily for cybersecurity education in a classroom. It includes a number of security tools, covering network scanning, traffic analysis, web and password testing, and firewall configuration, as well as a number of custom applications, written in Python and released under General Public Licence 3. The principal learning tool is called CarotOS Poligon, a student/teacher application pair for practicing penetration testing in an isolated, local classroom environment.

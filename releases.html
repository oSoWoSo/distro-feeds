  • 2026-11-07SystemRescue 13.03DistroWatch · Homepage · ISO

    SystemRescue is an Arch-based Linux system on a bootable DVD or USB drive, designed for repairing a system and rescue data after a crash. It also aims to provide an easy way to carry out administration tasks on a computer, such as creating and editing hard disk partitions. It contains many useful system utilities (GNU Parted, PartImage, FSTools) and some basic ones (editors, Midnight Commander, network tools). It aims to be very easy to use. The kernel of the system supports all of today's most important filesystems, including ext2, ext3, ext4, ReiserFS, Reiser4, Btrfs, XFS, JFS, VFAT, NTFS, ISO9660, as well as network filesystems, such as Samba and NFS.

  • 2026-11-07Spaced 11.26DistroWatch · Homepage · ISO

    Spaced Linux is a desktop Linux distribution based on Devuan's "Unstable" branch and featuring the MATE desktop environment on top of the Compiz compositing window manager. Like its parent, it uses the SysV init system. The distribution boots into a barebones live environment which offers the possibility to install Spaced Linux to a hard disk using the Calamares system installer. Once installed, a Welcome screen provides single-click options to extend the distribution by installing a collection of suggested applications (for web, office and multimedia use), adding SpacedBazaar (for Flatpak applications) or installing the NVIDIA graphics drivers. Spaced Linux intends to be modular, transparent and free of systemd, accessible to both beginners and advanced Linux users.

  • 2026-11-06FreeBSD 15.2-BETA1DistroWatch · Homepage · ISO

    FreeBSD is a UNIX-like operating system for the i386, amd64, IA-64, arm, MIPS, powerpc, ppc64, PC-98 and UltraSPARC platforms based on U.C. Berkeley's "4.4BSD-Lite" release, with some "4.4BSD-Lite2" enhancements. It is also based indirectly on William Jolitz's port of U.C. Berkeley's "Net/2" to the i386, known as "386BSD", though very little of the 386BSD code remains. FreeBSD is used by companies, Internet Service Providers, researchers, computer professionals, students and home users all over the world in their work, education and recreation. FreeBSD comes with over 20,000 packages (pre-compiled software that is bundled for easy installation), covering a wide range of areas: from server software, databases and web servers, to desktop software, games, web browsers and business software - all free and easy to install.

  • 2026-11-06AI-2 20261106DistroWatch · Homepage · ISO

    AI-2 is a minimalist desktop Linux distribution providing a local artificial intelligence (AI) assistant. It is based on Artix Linux, an Arch-derived distribution without the systemd init suite, and uses the Xfce desktop. At first login, a setup wizard detects the user's hardware, assigns a capability tier, installs the matching llama.cpp build (an app that runs the latest open model), downloads a fitting model and calculates an AI score that decides which large language models are recommended. The distribution also provides a custom AI-2 Chat application, available in the menu, that opens a chat page in the web browser; it uses an OpenAI-compatible API on localhost, so no data leave the user's computers.
